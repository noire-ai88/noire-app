NOIRE — PWA package

Что внутри:
- index.html — текущий интерфейс NOIRE с сохранёнными пользовательскими иконками разделов
- manifest.webmanifest — настройки устанавливаемого приложения
- service-worker.js — кэширование оболочки для повторного запуска
- icons/ — иконки приложения

Важно:
- Это устанавливаемая веб-версия (PWA), а не нативный IPA-файл.
- Для установки на iPhone сайт должен быть опубликован по HTTPS.
- Чат пока работает в демонстрационном режиме: языковая модель ещё не подключена.
- Не добавляйте API-ключи в index.html или другие публичные файлы.
- Данные текущего прототипа сохраняются локально в браузере; iCloud/аккаунт NOIRE пока не подключены.

Установка на iPhone после публикации:
1. Откройте адрес сайта в Safari.
2. Нажмите «Поделиться».
3. Выберите «На экран Домой».
4. Включите «Открывать как веб-приложение», если этот переключатель доступен.
5. Нажмите «Добавить».

Следующий этап разработки: публикация по HTTPS, затем безопасный серверный API для настоящей модели и отдельная система аккаунтов/синхронизации.
